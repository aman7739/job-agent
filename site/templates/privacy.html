Privacy Policy

Last updated: October 2026 • Single-User Personal Application

1. Personal Single-User Scope

The Job Digest Agent is an autonomous, private software application developed and operated strictly for personal use by a single candidate. It does not provide public registration, multi-user accounts, or software-as-a-service offerings to third parties.

2. Data Collection & Processing

The system processes only two categories of information:

  • Candidate Profile: Technical skills, educational graduating batch year (2027), target roles, preferred work locations, and personal notification addresses. This data is stored securely in an isolated database and is never shared or exported publicly.
  • Public Job Postings: Publicly accessible job listings obtained via official ATS endpoints, search APIs, and forwarded alert emails.

3. Cookies & Tracking

This public project website does not use cookies, local storage trackers, or third-party web analytics. The private administrative dashboard uses a single HTTP-only, cryptographically signed session cookie exclusively for authentication.

4. Third-Party Integrations

Notification delivery relies on official Telegram Bot APIs and standard SMTP email infrastructure. No candidate application data is sold, monetized, or shared with external advertising networks.

5. Data Retention & Erasure

All job index data, seen fingerprints, and digest logs are retained strictly in the candidate's private database. The candidate retains full authority to wipe or export records via provided backup utilities at any time.
